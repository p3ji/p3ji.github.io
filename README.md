# Canada Connect

A Phase 1 frontend prototype for discovering federal, provincial, and municipal services by life event. The service catalogue is curated mock data, the assistant is scripted, and the watchlist is saved in this browser.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000. Use `npm run typecheck` and `npm run build` to verify the scaffold.

## Scope

The prototype does not determine eligibility or submit applications. Benefit amounts are deliberately shown as variable where they depend on personal circumstances. Each service links to its official government page for current rules and applications.
